# Workload Security

This module develops the reasoning needed to explain security context controls and their limits.

## Learning Goals

- Explain security context controls and their limits.
- Compare the Privileged, Baseline and Restricted Pod Security profiles.
- Identify sensitive credential handling and excessive privileges.
- Distinguish image vulnerability checks from artifact identity checks.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
