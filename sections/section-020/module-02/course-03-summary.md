# Summary

Security contexts limit process privileges and resource access. Pod Security profiles establish admission expectations, with enforcement, warnings and audits serving different purposes. Applications need compatible filesystem and user configurations.

Credentials require scoped access, careful handling and rotation. Supply chain controls distinguish artifact identity, origin, component inventory and known vulnerabilities. Several checks together reduce risk, but no single check proves complete application security.
