# Identity And Access

This module develops the reasoning needed to distinguish authentication, authorization and admission.

## Learning Goals

- Distinguish authentication, authorization and admission.
- Explain ServiceAccounts and token-based workload identities.
- Compare Role, ClusterRole and their bindings.
- Apply least privilege to an API permission scenario.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
