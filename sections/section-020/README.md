# Security

This section teaches identity and access; workload security. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario.

You will work through Identity And Access, Workload Security. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. An original YAML question bank is prepared for the end of the section, with answer explanations for future quiz integration.

## Learning Outcomes

- Distinguish authentication, authorization and admission.
- Explain ServiceAccounts and token-based workload identities.
- Compare Role, ClusterRole and their bindings.
- Apply least privilege to an API permission scenario.
- Explain security context controls and their limits.
- Compare the Privileged, Baseline and Restricted Pod Security profiles.
- Identify sensitive credential handling and excessive privileges.
- Distinguish image vulnerability checks from artifact identity checks.
