# Introduction

This introduction explains how to use the Container Orchestration course. Welcome To The Course describes who the course is for, what you can do at the end, the words it uses and the example application. Get Your Machine Ready lists the tools to install, the `astrona` commands you use every day and what to do when a start goes wrong. How This Course Is Made describes how the content is written and checked, who maintains it, how to report a mistake and the license.

The course starts with networking.
