# Troubleshooting

This section teaches diagnosing orchestration failures; diagnosing cluster services. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario.

You will work through Diagnosing Orchestration Failures, Diagnosing Cluster Services. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. An original YAML question bank is prepared for the end of the section, with answer explanations for future quiz integration.

## Learning Outcomes

- Use status, conditions and events to identify a failed lifecycle stage.
- Distinguish placement failures from preparation failures.
- Explain image pull errors and startup errors.
- Choose evidence before making a corrective change.
- Distinguish a node problem from a single workload problem.
- Separate DNS resolution from Service backend connectivity.
- Explain how storage and resource pressure affect workloads.
- Choose the smallest diagnostic scope supported by evidence.
