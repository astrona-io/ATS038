# Diagnosing Cluster Services

This module develops the reasoning needed to distinguish a node problem from a single workload problem.

## Learning Goals

- Distinguish a node problem from a single workload problem.
- Separate DNS resolution from Service backend connectivity.
- Explain how storage and resource pressure affect workloads.
- Choose the smallest diagnostic scope supported by evidence.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
