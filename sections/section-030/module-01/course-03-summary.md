# Summary

Troubleshooting narrows the failed lifecycle stage through desired state, conditions, events and container details. Placement rules, resource requests and storage dependencies can all block progress before application execution.

Image preparation, process startup and repeated crashes are separate failures. Evidence must identify the affected container and current cause. A focused correction needs verification of both the failed stage and the application's intended behavior.
