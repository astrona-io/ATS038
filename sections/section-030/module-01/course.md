# Diagnosing Orchestration Failures

This module develops the reasoning needed to use status, conditions and events to identify a failed lifecycle stage.

## Learning Goals

- Use status, conditions and events to identify a failed lifecycle stage.
- Distinguish placement failures from preparation failures.
- Explain image pull errors and startup errors.
- Choose evidence before making a corrective change.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
