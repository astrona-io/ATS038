# Summary

Access modes describe supported node or Pod attachment arrangements. Volume mode determines whether an application receives a filesystem or raw block device. Driver support and application concurrency rules determine what is usable and safe.

Reclaim policies govern storage after claim release, separately from Pod deletion. Retention, replication and backup protect different outcomes. A sound recovery plan includes the actual backend, object lifecycle policies and application consistency requirements.
