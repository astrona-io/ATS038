# Storage Decisions

This module develops the reasoning needed to distinguish ReadWriteOnce from ReadWriteOncePod.

## Learning Goals

- Distinguish ReadWriteOnce from ReadWriteOncePod.
- Compare filesystem and block volume modes.
- Predict Retain and Delete reclaim policy behavior.
- Explain why persistence, replication and backup are different properties.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
