# Volumes And Application State

This module develops the reasoning needed to compare container-local, ephemeral and persistent storage lifecycles.

## Learning Goals

- Compare container-local, ephemeral and persistent storage lifecycles.
- Explain the PersistentVolume and PersistentVolumeClaim relationship.
- Describe StorageClass-based dynamic provisioning.
- Identify the CSI driver's role in storage operations.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
