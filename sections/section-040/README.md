# Storage

This section teaches volumes and application state; storage decisions. These ideas help you explain system behavior and choose a suitable approach in a KCNA scenario.

You will work through Volumes And Application State, Storage Decisions. Each module introduces its goals, teaches the concepts through examples, and closes with a summary. An original YAML question bank is prepared for the end of the section, with answer explanations for future quiz integration.

## Learning Outcomes

- Compare container-local, ephemeral and persistent storage lifecycles.
- Explain the PersistentVolume and PersistentVolumeClaim relationship.
- Describe StorageClass-based dynamic provisioning.
- Identify the CSI driver's role in storage operations.
- Distinguish ReadWriteOnce from ReadWriteOncePod.
- Compare filesystem and block volume modes.
- Predict Retain and Delete reclaim policy behavior.
- Explain why persistence, replication and backup are different properties.
