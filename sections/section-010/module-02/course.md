# Services And External Access

This module develops the reasoning needed to explain Service selectors, ports and EndpointSlices.

## Learning Goals

- Explain Service selectors, ports and EndpointSlices.
- Compare ClusterIP, NodePort and LoadBalancer Services.
- Distinguish Ingress from a Service and its implementation.
- Explain the role separation in the Gateway API.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
