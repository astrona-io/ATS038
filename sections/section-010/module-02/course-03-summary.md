# Summary

Services identify access points and backend port mappings. Selector-based Services depend on labels and endpoint readiness, which EndpointSlices help represent. The application still needs a working listener.

ClusterIP, NodePort and LoadBalancer provide different exposure patterns. Ingress and Gateway resources describe application routing implemented by controllers. Resource creation, address allocation and successful external requests are separate outcomes.
