# Pod Networking

This module develops the reasoning needed to explain Pod addresses and communication in the Kubernetes network model.

## Learning Goals

- Explain Pod addresses and communication in the Kubernetes network model.
- Identify the network plugin's role and the CNI interface.
- Explain Service discovery through DNS.
- Distinguish name resolution from application reachability.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
