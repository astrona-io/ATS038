# Traffic Control

This module develops the reasoning needed to explain how NetworkPolicy selects and isolates Pods.

## Learning Goals

- Explain how NetworkPolicy selects and isolates Pods.
- Predict whether both traffic directions permit a connection.
- Distinguish network policy from service mesh capabilities.
- Explain TLS encryption and certificate verification.

## Before You Start

Read the examples as descriptions of system behavior. No cluster, account, laboratory or installed tool is required. Technical terms are defined where they are used.
